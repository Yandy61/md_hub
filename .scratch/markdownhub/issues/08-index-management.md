# 08 — 索引管理（增/删/源丢失）

**What to build:** 管理员界面：输入本地路径把单个 md 文件或目录加入索引（创建后访客立即可见）；删除外部索引条目 = 仅取消索引、绝不触碰原文件（UI 文案为"取消共享"而非"删除"）；源路径消失时条目保留并标记"源丢失"，恢复后自动回归。索引路径不做黑名单限制。

**Blocked by:** 03 — 目录索引与树形浏览, 07 — 管理员认证

**Status:** ready-for-agent

- [x] 界面上新增文件/目录索引后，访客列表立即呈现
- [x] 取消索引后原文件完好无损，访客不再可见
- [x] 删除/移动源路径后条目保留并显示"源丢失"，路径恢复后自动回归
- [x] 非管理员无法执行任何索引管理操作
- [x] HTTP seam 测试覆盖新增（file/dir）、取消索引、源丢失与恢复
